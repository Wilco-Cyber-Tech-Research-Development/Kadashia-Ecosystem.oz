# Sovereign Control Node

Simple unified landing page for all active DevOps projects under our blueprints.

Provides a single, clean view of every project currently under the Digital Sovereignty framework so nothing is lost over time. Vercel, AWS and Google Cloud deployments will be added once the assets assessment is complete.

## Contents
- `index.html` — the landing page itself (static, no build step required)

## How to view
Open `index.html` in any browser, or serve it from any static host (GitHub Pages, Vercel, Netlify, etc.).
